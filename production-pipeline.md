# Content Production Pipeline

1. Read the complete passage.
2. Define the episode's purpose.
3. Break it into scenes.
4. Draft narration.
5. Separate quotation from paraphrase.
6. Review for biblical accuracy.
7. Create image prompts.
8. Create motion prompts.
9. Generate and review assets.
10. Add narration, music, captions, and citations.
11. Complete final review.
12. Publish with a link to the passage.
